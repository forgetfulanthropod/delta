# Delta Roadmap (Current)

See [README.md](./README.md) for the current product description and status.

See [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md) for the living plan (mission, pillars, key initiatives) and summarized historical phases.

## Current Priorities (as of latest)

1. **AI Quality**
   - Move beyond prompt-only generation toward better image understanding.
   - Improve material suggestions and realistic transformations.

2. **Data & Persistence**
   - Expand beyond basic Zustand localStorage (web).
   - Add proper project history, save/load, and backend storage options.

3. **Native & Cross-Platform**
   - Complete vision-camera integration and mobile camera experience.
   - Ensure consistent experience and performance on iOS/Android.

4. **Worker Experience**
   - Build on recent improvements (trade filter, Flickity photo carousels per project, direct estimated costs shown as "ready to go").
   - Add claiming/assignment flows, better integration with owner-sourced data, and actual scheduling visibility for workers.

5. **Owner Flow & Cost Transparency**
   - Surface estimated costs more directly in the owner journey (in addition to or instead of "Send to Sourcing").
   - Continue making costs feel "ready to go" across the product.

6. **Polish & Production Readiness**
   - Reduce hardcoded/demo data.
   - Better error states, empty states, loading.
   - Real retailer links/data where possible.
   - Deployment (web + backend) and basic CI.

## Recent Wins (to celebrate)
- Worker dashboard with meaningful jobs, filters, flickable photos, and per-job estimated costs.
- Desktop UI no longer feels overly wide (content constraints).
- Owner flow remains solid with persistence and consistent styling.

Contributions and feedback welcome. When in doubt, start from the limitations listed in README.md and the [Current Priorities & Key Initiatives](./DEVELOPMENT_PLAN.md#current-priorities--key-initiatives) section in DEVELOPMENT_PLAN.md.
